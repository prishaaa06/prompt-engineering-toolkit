# Python Portfolio Projects

Small, inspectable projects showcasing different programming skills. All use Python's standard library, include example inputs, and have unit tests.

| Project | Topics |
| --- | --- |
| [Student Performance Analyzer](student-performance-analyzer/) | CSV, descriptive statistics, rankings, data validation |
| [Expense Tracker](expense-tracker/) | SQLite, SQL aggregation, CLI, monetary values |
| [Job Description Skill Matcher](job-description-skill-matcher/) | NLP basics, regex, skill extraction, explainable coverage |

## Tests
Run tests within each project directory:

```bash
python -m unittest discover -p "test_*.py"
```

These projects are educational examples and are not production services. Follow the individual README files to run each project.

For a stronger GitHub portfolio, consider moving each folder to its own repository, adding screenshots or demo GIFs, and documenting future improvements.
